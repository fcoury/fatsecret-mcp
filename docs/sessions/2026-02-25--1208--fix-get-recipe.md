# Integración de get_recipe para visualización de ingredientes de recetas
**Fecha:** 2026-02-25 12:08  
**Archivos:** src/index.ts, skills/fatsecret-nutritionist/references/capabilities.md  
**Duración:** ~15 min  
**Dificultad:** 1 estrella  
**Estado:** Completado

## Objetivo

Añadir la capacidad de consultar los detalles internos e ingredientes de una receta específica usando su ID.

## Cambios clave

1. Se añadió la herramienta interna 'get_recipe' al toolRegistry de 'src/index.ts', mapeándola al endpoint 'recipe.get.v2'. 2. Se actualizó el archivo 'capabilities.md' de la Skill para exponer este nuevo método al agente.

## Errores / Incidencias

El agente podía buscar recetas (search_my_recipes) y recuperar su ID, pero no existía una herramienta para inspeccionar el contenido (ingredientes, alérgenos, cantidades) de esa receta.

## Solución aplicada

Implementar un wrapper directo sobre el método 'recipe.get.v2' de la API de FatSecret, cerrando el ciclo: Búsqueda -> Identificación de ID -> Recuperación de detalles.

## Resultado

El agente ahora puede ver los componentes exactos de las recetas del usuario ('Libro de Cocina'), completando la integración del flujo de recetas.
